# Simple Trees Beat Deep Networks at Attributing VMProtect-Protected Malware

A leakage-free, forgery-aware evaluation of static APT-family attribution of VMProtect-protected malware.

**Project page:** https://panzerjagerwang.github.io/simple-trees-vmprotect/

Gradient-boosted trees on the loader-relevant PE header fields attribute protected executables to their
advanced persistent threat family more accurately (90.9% protected-test macro-F1) than eight image and byte
networks and a multi-view Transformer (ObfusFormer), while training in seconds on a CPU.

Manuscript under review (IEEE Transactions on Dependable and Secure Computing).
Code and derived data will be released at this repository upon publication.

Authors: Xubo Fang (corresponding), Haochen Dong, Jiaqing Wang, Sicheng Han (Kanazawa University).
Fang, Dong, and Wang contributed equally.
